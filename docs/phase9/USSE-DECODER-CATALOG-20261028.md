# USSE decoder coverage and compiler integration — 2026-10-28

This investigation uses the pinned original SDK35 decoder with its own SGX535/rev121 descriptor. It does not enable an instruction, change a shader gate or install a driver. The user requested broad USSE disassembly and asked to prioritize REA for lower token use. Existing source implementations and physical evidence remain authoritative.

## Recovered decoder

REA/Ghidra analyzed all **171 internal routines reachable through reported non-external/non-thunk call edges** from the decoder and its dispatcher. Their complete function bodies contain **18,959 host x86 assembly lines**. No listed internal callee remains unanalyzed, no unresolved call was reported and no native value-flow record was truncated. External/thunk boundaries remain boundaries; this is not a claim that all hardware encodings or semantics have been proved.

The dispatcher at `0x08298be3` selects `word1 >> 27`. Feature predicate `0x08299b38` reads feature-word0 bit27; the original SGX535 table at `0x082d2800` starts with words `0, 0x40000000`, so the scalar route is selected. Group27 is rejected by the two absent feature-word0 predicates. Other cores in the SDK use additional routes: their presence does not qualify them for SGX535.

The shared operation dictionary at `0x082ceec0` contains **370 entries / 368 distinct names**, with 12-byte records: name pointer, uninterpreted flags, and operand count used by the formatter. These are internal dictionary IDs, **not hardware opcode values**. The table is shared across cores. The 58 error names were recovered separately.

Important correction: wrapper `0x0829921b` returns false on decode error, otherwise `bool(decoded_internal_flags & 0x20000)`. It is not an acceptance boolean. Controlled examples are `00000000 f8000140 -> nop, return0` and `00000000 f8040140 -> nop.end, return1`. Historical reports correctly retained this integer uninterpreted; their records are unchanged. New tooling classifies textual decoder errors from the original error table and never uses the boolean as a GPU admission gate.

## Controlled CPU decoding

An initial 8,192-record matrix plus 33,170 mnemonic-guided bit/field probes produced **41,362 checked records**: 39,446 non-error texts, 1,916 explicit decoder errors and **169 distinct sampled accepted mnemonic spellings**. All batches completed with the original shim's canaries and termination checks intact. The bounded exploration converged for its configured mutations; it did not enumerate 2^64 encodings. Absence from the sample is not an unsupported-hardware conclusion. All generated bytes stayed on CPU.
